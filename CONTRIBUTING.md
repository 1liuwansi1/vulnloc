# Contributing (pending public release)

Do not edit `experiments/*_frozen/`, historical paper numbers or reference JSON
to make tests pass. Changes belong in wrappers, new analyses or future experiments.
Keep S0/S1 separate, failures retained and entry-level inference unchanged.
Run `vulnloc verify`, `vulnloc reproduce`, unittest and the candidate scanner.
Discuss any new model collection, licensing, dataset or scientific claim first.
No paid calls, remote upload or deployment are part of the current workflow.
