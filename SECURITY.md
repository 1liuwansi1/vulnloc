# Security

The supported CLI is offline. Historical frozen runners are evidence, not a safe
sandbox, and may invoke paid APIs if run manually. Never supply keys to them.
Do not execute untrusted configs, repository scripts or model-generated code.
No raw text, credentials or private logs should be attached to issue reports.

Maintainer security contact is **PENDING** approval; no public disclosure channel
is configured. Until then, report concerns directly to the research owner through
an already trusted private channel. Do not publish secrets in a GitHub issue.
Regex scanning cannot certify absence of all sensitive information.
